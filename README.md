📖 About the Project
Farmer Trade is a comprehensive agricultural web platform designed to empower farmers by providing real-time market prices, direct buyer connections, logistics management, and an integrated AI-powered agricultural advisor (FarmerDesk AI). The platform bridges the gap between farmers and buyers, ensuring transparent and fair agricultural trade.
✨ Key Features
 * 🌾 Live Mandi Prices & APMC Rates: Check real-time market prices, price summaries, and daily market arrivals across various states, districts, and markets (integrated with Agmarknet data).
 * 🤝 Direct Buying & Selling: Seamless role-based registration for both Farmers (to list and sell crops) and Buyers (to purchase crops and review deals).
 * 🤖 FarmerDesk AI Advisor: An online agricultural advisor powered by Google Gemini that handles instant mandi prices, advisory, crop health tips, fertilizer/pest control guidance, logistics booking, and buyer negotiations in both English and Hindi.
 * 📦 Crop & Storage Management: Easily list crops, manage active storage batches in warehouses, and monitor cold storage reservations.
 * 🚚 Logistics & Tracking: Book pickup logistics for harvested crops and track active transportation statuses.
 * 💬 Messaging & Transactions: Integrated chat system for direct communication and transparent trade settlements.
 * 🌐 Multilingual Support: Accessible in multiple languages including English and Hindi.
🛠️ Tech Stack & Architecture
 * Frontend: Built with a modern web development stack (running locally via Vite at localhost:5173).
 * AI Integration: Google Gemini AI (FarmerDesk AI) for instant multilingual agricultural queries and advice.
 * Data Sources: Real APMC Mandi prices and daily market arrivals (Agmarknet).
🚀 Getting Started
Prerequisites
Make sure you have Node.js and a modern package manager installed.
Installation & Running Locally
 * Clone the repository:
   git clone https://github.com/your-username/farmer-trade.git
cd farmer-trade

 * Install dependencies:
   npm install

 * Run the development server:
   npm run dev

 * Open your browser and navigate to http://localhost:5173.
🖥️ Platform Walkthrough
 * Home & Landing Page: Overview of market prices (e.g., Wheat trends), features, and quick access to the AI advisor.
 * User Registration: Simple onboarding workflow allowing users to sign up as a Farmer or a Buyer.
 * Farmer Dashboard: Centralized hub tracking listed crops, active logistics, pending buyer offers, stored batches, net realizations, and direct links to check market prices or chat with FarmerDesk AI.
 * Market Prices Page: Filter live APMC Mandi prices by state, district, market name, and specific crop types (such as Rice or Pulses).
